# 课堂触屏网页优化 · 2026-10-05

网址：https://yxiaoyu906-sketch.github.io/1/history1831/

学生平板与教师触屏一体机使用同一操作界面：方向按钮行走、右侧拖动转向、点击高亮物件交互。入口增加全屏运行与课前缓存。浏览器不支持系统全屏时，场景铺满可用页面。

首屏压缩传输量从 153,369,166 字节降至约 27,610,008 字节；华沙第二幕约 27,352,920 字节，在第一幕开始后准备。全部场景传输合计约 55 MB。经 SHA-256 校验的资源缓存在浏览器内，后续优先复用；清理浏览器数据或存储配额不足会重新下载，仍需联网打开网页。

保留全部 15 个交互人物、2 个跑动人物及课堂内容。装饰物使用原有网格 LOD 简化、纹理压缩，降低三维渲染比例、阴影与粒子开销。原版桌面项目源文件与桌面运行版不变。

步行速度保留 1.35，垂直起伏幅度 0.04，使用原版节奏。触摸与模拟鼠标避免重复计入转向，限定转向手指，松手与失去焦点时释放输入。长正文置于可滚动且裁切的区域，关闭与翻页按钮固定保留。横竖屏自动调整界面比例。

验证：分包第一幕独立运行、第二幕挂载、全部人物与历史图片、各交互页在 1280×720、1024×768、390×844 下的面板与按钮边界、步行起伏、转向停止与重复输入抑制；加载器验证解压顺序、校验缓存复用、最多三个并行下载、第二幕挂载与全屏入口。

实际手机、平板、一体机的持续帧率与触摸手感尚未实机测量。Mac 上的原生 Compatibility 渲染截图可以检查布局，但不能代替移动浏览器性能验收。

修改后的网页脚本与 Godot 脚本补丁保存在 source/WebOptimization；原始资源仍保留在先前公开的归档中。最新网页以 manifest.json 引用的 classroom-room / classroom-warsaw 分片为准。
