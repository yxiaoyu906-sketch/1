# 课堂触屏网页清晰版 · 2026-10-06

网址：https://yxiaoyu906-sketch.github.io/1/history1831/?v=classroom-4

学生平板与教师触屏一体机统一操作：方向按钮行走、右侧拖动转向、点击高亮物件交互。全屏、课前缓存、方向键安全区定位和正文滚动保留。

画质：三维渲染比例恢复 1.0，开启 2× MSAA；画布考虑高分屏像素密度，最高 2×、最长边 2560、总像素约 320 万。贴图恢复远近过滤链，主要地面、地毯及人物基础色图提升至 1024，天空恢复 1774×887。法线与粗糙度图使用无损 WebP，其他图使用高质量 WebP。两个 GPU 导入别名共用同一贴图内容。

联动：快速拖动位移不再按事件和物理帧截断，每个画面帧完整消费累计位移。移动与转向手指独立绑定和释放；保留步速 1.35、起伏 0.04 及原版节奏。触屏操作期间暂缓第二幕后台分片下载，松手且短暂空闲后继续；点击进入第二幕时允许立即继续准备资源。两幕在遮罩下预热不同视角，减少首次转向时的材质准备停顿。第二幕遮罩保持到完整场景及首批画面就绪。

首屏 36,331,170 字节（约 36.3 MB），第二幕 47,845,886 字节（约 47.8 MB），合计约 84.2 MB；首屏比最初 153 MB 减少约 76%。SHA-256 校验后缓存，后续优先复用；清理浏览器数据会重新下载，仍需联网打开网页。

验证：405 项检查通过，完成 Mac Compatibility 原生渲染，覆盖七种比例。新增高画质渲染、视角预热、长拖动完整处理、事件分批一致性、双指同时行走转向、独立松手和连续转向检查。加载器验证高分屏、安全区、画布像素上限、后台下载手势让行、缓存复用及转场遮罩时机。

真实手机、平板与一体机的持续帧率、触摸手感尚未实机测量。桌面原 Godot 源码与 macOS/Windows 运行版保留；Web 补丁位于运行版本/Web/source/WebOptimization。
