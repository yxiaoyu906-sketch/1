# 课堂触屏网页双指修复版 · 2026-10-06

网址：https://yxiaoyu906-sketch.github.io/1/history1831/?v=classroom-5

学生平板与教师触屏一体机统一操作：方向按钮行走、右侧拖动转向、点击高亮物件交互。全屏、课前缓存、方向键安全区定位和正文滚动保留。

画质：三维渲染比例恢复 1.0，开启 2× MSAA；画布考虑高分屏像素密度，最高 2×、最长边 2560、总像素约 320 万。贴图恢复远近过滤链，主要地面、地毯及人物基础色图提升至 1024，天空恢复 1774×887。法线与粗糙度图使用无损 WebP，其他图使用高质量 WebP。两个 GPU 导入别名共用同一贴图内容。

联动：已复现长按移动超过 0.7 秒后，兼容鼠标事件可能被当成转向输入的问题；旧版两幕四方向共 8 项回归检查失败。修复后以完整手势生命周期隔离鼠标输入，移动、转向及第三个手指分别跟踪。视角使用同一手指的绝对坐标差，统一在全局输入处理一次；跨过方向键也保持原手势归属。右侧转向区显式覆盖完整高度；松手、失焦或画布尺寸变化时清除残留位移，重新按下从新位置开始。保留步速 1.35、起伏 0.04、清晰画质、全屏和双幕遮罩。触屏期间暂缓后台资源下载与视角预热保留。

首屏 36,331,507 字节（约 36.3 MB），第二幕 47,845,886 字节（约 47.8 MB），合计约 84.2 MB；首屏比最初 153 MB 减少约 76%。SHA-256 校验后缓存，后续优先复用；清理浏览器数据会重新下载，仍需联网打开网页。

验证：509 项检查通过，完成 Mac Compatibility 原生渲染及无界面检查。两幕四方向分别进行 90 帧实际 Viewport 双指事件链测试，混入普通 device=0 鼠标事件、方向手指大幅移动、不一致 relative、GUI 重复分发和第三个手指；逐帧转向量稳定。另覆盖独立松手、索引重用、跨方向键拖动、窗口尺寸变化和失焦。七种比例、完整教学交互、画质及加载器缓存/转场检查通过。

真实手机、平板与一体机的持续帧率、触摸手感尚未实机测量。桌面原 Godot 源码与 macOS/Windows 运行版保留；Web 补丁位于运行版本/Web/source/WebOptimization。
